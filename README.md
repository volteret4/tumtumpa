# Tumtumpá

Un blog de opiniones personales sobre discos, hecho con [Hugo](https://gohugo.io/).

## Para qué sirve

Para guardar y compartir lo que opino de cada disco que escucho.

[Versión pública](https://volteret4.github.io/tumtumpa/).

## Instalación individual

Necesitas Hugo en su edición extendida. Los temas son submódulos.

```bash
git clone --recurse-submodules https://github.com/volteret4/tumtumpa.git
```

```bash
cd tumtumpa && hugo server
```

Se abre en <http://localhost:1313>. Al subir a `main`, GitHub Actions publica la web.

## REPEAT-ONE

Este proyecto se enlaza desde el índice de [REPEAT-ONE](https://volteret4.github.io/repeat-one-web/), pero no se instala con él. Para los módulos que sí se instalan juntos, [mira su instalación](https://github.com/volteret4/repeat-one-web#instalación).

Tumtumpa Discover, que comparte nombre y sí se instala con REPEAT-ONE, está en [escuchowsky](https://github.com/volteret4/escuchowsky).
